# talash Python — آموزش پایتون از صفر تا متوسط

وب‌سایت آموزشی کامل، حرفه‌ای و ریسپانسیو پایتون به زبان فارسی (RTL) با تم مشکی-بنفش.

**سازنده و مدرس: ماهان شریفی**

---

## امکانات

- ۱۲ درس کامل فارسی از نصب پایتون تا پروژه عملی (متغیرها، شرط‌ها، حلقه‌ها، لیست‌ها، دیکشنری، توابع، رشته‌ها و...)
- ۵۵ نمونه کد با خروجی واقعی و توضیح + دکمه کپی و دکمه «اجرا در محیط کد»
- ۳۶ تمرین عملی با راهنما و پاسخ قابل باز شدن
- ۶۰ سوال آزمون چهارگزینه‌ای (پاسخ درست با توضیح، نمره، بهترین نمره، تلاش دوباره)
- محیط کدنویسی شبیه VS Code با هایلایت سینتکس و **اجرای واقعی پایتون در مرورگر با Pyodide** (بدون خروجی ساختگی)
- سیستم پیشرفت با LocalStorage: درس‌های تکمیل‌شده، نمرات، درصد پیشرفت، «ادامه یادگیری» و بازنشانی پیشرفت
- جستجوی درس‌ها، حالت تمرکز بدون حواس‌پرتی، صفحه درباره ما و راهنما، انیمیشن‌های نرم و طراحی کاملاً موبایل‌دوست

## روش اجرا

### روش ۱ — ساده‌ترین راه (بدون نصب چیزی)
فایل `index.html` را دابل‌کلیک کنید؛ سایت در مرورگر باز می‌شود.

یا نسخه تک‌فایل `talash-python.html` را باز کنید (همه CSS و JS داخل همان یک فایل است).

### روش ۲ — با سرور محلی (پیشنهادی برای توسعه)
```bash
cd talash-python
python3 -m http.server 8000
# سپس در مرورگر: http://localhost:8000
```

> توجه: برای اجرای واقعی کدها در «محیط کد»، بار اول به اینترنت نیاز است (دانلود مفسر Pyodide حدود ۱۰ مگابایت از CDN). بقیه سایت حتی بدون اینترنت هم کار می‌کند؛ فقط به‌جای خروجی ساختگی، پیام نیاز به اینترنت نمایش داده می‌شود.

## انتشار روی اینترنت

این پروژه کاملاً استاتیک است (بدون سرور و دیتابیس) و روی هر هاستی قرار می‌گیرد:

### GitHub Pages (رایگان)
1. اکانت GitHub بسازید و یک ریپازیتوری جدید (مثلا `talash-python`) بسازید.
2. کل محتوای پوشه `talash-python` را آپلود کنید (فایل‌های `index.html`، پوشه `css/` و `js/`).
3. در تنظیمات ریپو → **Pages** → Branch را روی `main` و پوشه `/ (root)` بگذارید و Save کنید.
4. بعد از چند دقیقه سایت روی `https://USERNAME.github.io/talash-python/` در دسترس است.

### Netlify (رایگان، Drag & Drop)
1. به app.netlify.com بروید و وارد شوید.
2. در بخش Sites فایل `talash-python.zip` را مستقیم روی صفحه بکشید و رها کنید.
3. چند ثانیه بعد لینک عمومی سایت آماده است (قابل اتصال به دامنه اختصاصی).

### Vercel (رایگان)
1. در vercel.com پروژه را از GitHub import کنید (یا drag & drop پوشه).
2. تنظیمات پیش‌فرض کافی است؛ Build Command و Output Directory خالی بگذارید.

### هاست اشتراکی (سی‌پنل و مشابه)
کل محتوای پوشه را از طریق File Manager یا FTP داخل `public_html` آپلود کنید؛ همین.

```
│   ├── data-lessons-c.js ← درس‌های ۹ تا ۱۲ + آزمون‌ها

```

## نکات فنی

- بدون هیچ فریم‌ورک و بیلد‌تول؛ فقط HTML/CSS/JS خالص (ساده برای توسعه و تغییر)
- محتوای درس‌ها و آزمون‌ها داخل فایل‌های `js/data-lessons-*.js` است؛ برای افزودن درس جدید همان الگو را کپی کنید
- پیشرفت کاربر در کلید `talash_progress_v1` مرورگر ذخیره می‌شود
- اجرای پایتون: Pyodide نسخه ۰.۲۶.۲ داخل یک Web Worker با محافظ تایم‌اوت (حلقه بی‌نهایت برنامه را قفل نمی‌کند)
- تابع `input()` در محیط مرورگر پشتیبانی نمی‌شود؛ چنین کدهایی در درس‌ها با نسخه قابل اجرای جایگزین و توضیح همراه هستند
